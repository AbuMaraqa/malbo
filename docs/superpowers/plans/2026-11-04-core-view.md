# core-view Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Rebuild `core` as `core-view` on Vue + Inertia + PostgreSQL with feature parity and a measured speed budget.

**Architecture:** Port `core`'s domain layer (entities, repositories, services, migrations, tenancy) with fixes for PostgreSQL; replace Livewire/Filament with thin controllers, Inertia responses and Vue pages per module.

**Tech Stack:** PHP 8.4, Laravel 13, stancl/tenancy 3, nwidart 13, Inertia 3, Vue 3.5 + TS, Vite 8, Tailwind 4, Reka UI, PostgreSQL 18, Redis 8.

**Spec:** `docs/superpowers/specs/2026-11-04-core-view-design.md`

## Global Constraints

- `C:\laragon\www\core` is read only: copy from it, never write to it.
- User-facing strings use English keys in `Modules/<M>/Lang/ar.json`; Arabic RTL is the default locale.
- Writes go through services; pages and controllers never query migrated entities directly (`LayeringTest`).
- Tests run only on `core_view_central_testing` / `test_tenant_*`, on port 5433.
- The machine is RAM-constrained: single test files while working, full suite at phase ends.
- Commit per task on `main` of the new repository.

## Review Focus

1. A session cookie or cached value from store A used on store B: must be treated as a guest / miss. Test in Phase 1.
2. A query that compares a boolean column with `1` or an integer column with a non-numeric route id: PostgreSQL errors instead of coercing. Must return 404 or a validation error, not 500. Test in Phase 1.
3. Search typed in another letter case or in Arabic with a mixed locale: must find the product. Test in Phase 3.
4. Double-submit or stale form on admin pages (variations, repeaters): no duplicates, validation errors land on the right nested field. Test in Phase 3.
5. Storefront in an empty store: no empty section rendered, SSR does not crash on null settings. Test in Phase 4.
